# Give your AI agent an element

Turn on the element selector with **Alt+Shift+E** or the cursor button in the toolbar, then hover over the page.

| Action      | Result                                                                                          |
| ----------- | ----------------------------------------------------------------------------------------------- |
| Click       | Captures the element's selector, role, styles, component and source file, and HTML as Markdown. |
| Alt+click   | Captures a screenshot of the element instead.                                                   |
| Shift+click | Adds the element to a selection; **Enter** captures them all.                                   |
| ↑ / ↓       | Moves to the parent or child element.                                                           |

Each capture is copied and saved in the project's **Saved** list, then a dialog asks which agent gets it. Press its number (or Enter for the default); Esc keeps it saved without sending.
