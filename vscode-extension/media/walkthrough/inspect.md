# Give your AI agent an element

Turn on the element selector with **Alt+Shift+E** or the cursor button in the toolbar, then hover over the page.

| Action      | Result                                                                                        |
| ----------- | --------------------------------------------------------------------------------------------- |
| Click       | Copies the element's selector, role, styles, component and source file, and HTML as Markdown. |
| Ctrl+click  | Sends the element to the chat.                                                                |
| Shift+click | Adds the element to a selection; **Enter** copies them all.                                   |
| Alt+click   | Also saves a screenshot of the element.                                                       |
| ↑ / ↓       | Moves to the parent or child element.                                                         |
