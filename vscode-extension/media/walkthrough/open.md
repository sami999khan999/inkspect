# Browse inside VS Code

The browser opens in an editor tab, so it can sit next to your code. It runs a real Chromium, so sites, logins and dev servers behave as they do in Chrome.

- **Ctrl+L** focuses the address bar, **Ctrl+T** opens a tab, and **Ctrl+D** bookmarks the page.
- **Ctrl+click** a `http://localhost:…` link in the terminal to open it here.
- The **Browser** view in the Activity Bar has bookmarks, open tabs and settings.

The first start downloads Chromium once (about 150 MB).
